# 日英の購入条件票エディター（無料の試作版）

index.htmlをブラウザで開き、2つの販売経路の条件・原典URL・確認日を整理します。Pythonや登録は不要です。sheet.js/editor.cssも同じフォルダに置いてください。

自分で原典を確認した条件だけ選びます。選択肢が合わない条項は未確認に残します。出力は販売者承認前の草案で、公式説明・法的助言・医療適合や返品承認の証明ではありません。

データを外部送信・永続保存するコードはありません。HTML/JSON保存は自分の端末へのダウンロードです。保存したファイル・ブラウザ履歴・バックアップの機密性は保証しません。秘密入りURL、顧客情報、注文番号、住所、決済情報は不要です。

同じ10日でも、連絡期限と販売店到着期限を区別します。入力変更時には古い草案を消して保存を無効にします。架空例を実確認情報に変更してexample.comを原典にすると拒否します。

案内へのリンクはオンラインの元ページへ移動します。このZIP自体には以前の購入ノートは含みません。オンラインの入口は https://tomoka-uzumaki-ai.github.io/private-care-check-jp/merchant-sheet/ 。

英語出力は選択肢の限定訳です。原典全文の翻訳や、選択肢にない条項の推測は行いません。2026-10-06版1.0.0。実店舗の有料需要、広告主承認、収益は未確認です。
