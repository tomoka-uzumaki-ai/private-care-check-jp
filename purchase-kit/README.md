# ケア用品の購入前ノート｜日本語・English

日本でケア用品を買う前に、購入経路・返品条件・支払額を整理する無料資料です。非露骨な購入実務に限定し、使用体験、性能ランキング、医学的効果、性的な使用方法は扱いません。独立した説明で、各販売者の公式資料ではありません。

## 今の作業から読む

1. **どこで確認するか** → [日英の購入経路案内](01-channel-guide.md)。店舗での確認・通販・購入保留を分けます。
2. **注文前・開封前に読む** → [取消・返品・不良対応の条件票](02-before-opening.md)。原典同士の食違いと未知を隠しません。
3. **継続費用を比べる** → [費用の考え方](03-cost-guide.md)、[完成した計算例](cost-example-result.md)。例は架空で、商品の現価格ではありません。

## 計算を自分の条件で使う場合

Python 3がある端末で、JSONの値を自分の確認済み費用にして計算できます。`python3 cost.py cost-example.json`。入力と出力は端末内です。未知は`null`、無料と確認できた項目だけ0にします。実際の商品の比較キーと期間は自分で決める必要があります。

計算機は送信・ログイン・広告・購入処理を行いません。資料の閲覧やダウンロードはホスト先へ通信します。端末内ファイル・履歴・バックアップ・印刷物が他人に見えないことは保証しません。氏名・住所・カード情報・注文番号は不要です。

## English

These free notes cover purchase channels, seller-specific return conditions and cash costs for care products bought in Japan. They do not provide product-use instructions or medical recommendations. Read the bilingual channel guide first, then check cancellation and return conditions before ordering or opening goods.

The calculation example is synthetic. You can run the optional Python tool locally with your own verified tax-included JPY figures. Unknown costs are not treated as zero; future reward points are not deducted from today's payment. The tool does not verify that products are identical or appropriate for you.
